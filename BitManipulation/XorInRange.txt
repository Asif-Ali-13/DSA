----------------------------------------------------------------------------------------

problem statement:
Given two integers L and R. Find the XOR of the elements in the range [L , R].

----------------------------------------------------------------------------------------

approach:
    1. The XOR of numbers from 1 to n follows a predictable pattern based on n % 4.
    2. This pattern helps compute XOR from 1 to any number n in constant time.
    3. To get XOR of numbers in range [L, R],compute XOR(1 to R) and XOR(1 to L - 1).

----------------------------------------------------------------------------------------

code:

/* Function to find the XOR 
of numbers from 1 to n */
private int XORtillN(int n) {
    if(n % 4 == 1) return 1;
    if(n % 4 == 2) return n + 1;
    if(n % 4 == 3) return 0;
    return n;
}

/* Function to find the XOR 
of numbers from L to R */
public int findRangeXOR(int l, int r) {
    return XORtillN(l - 1) ^ XORtillN(r);
}

----------------------------------------------------------------------------------------

tc: O(1)
sc: O(1)
